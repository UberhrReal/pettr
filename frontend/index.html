Quick Start & Daily Workflow

PETTR is designed for high-focus execution. Log thoughts at stream of consciousness, and let the system organize tasks, projects, events, and reminders in real-time.

1 Natural Language & Priority Ingestion

Type any task naturally into the quick log bar. Priority words are automatically mapped and stripped:

Review propulsion test telemetry tonight 2359 top priority Schedule CAD model review Friday 1500 high priority Order 3D printer filament whenever

• top priority / p0: Ranks item into Position #1 and shifts other tasks down.
• high priority: Places item in the upper quartile of pending focus tasks.
• whenever / lowest priority: Routes to the bottom of the backlog.

2 Voice Speech-to-Text Input

Tap the microphone icon in the quick input bar to speak. PETTR streams real-time speech transcription directly into the box with tactile haptics. Tap again to stop and submit with Enter.

3 Horizontal Swipeable Ruler Timeline

Switch to the Timeline tab to view your day mapped across an interactive 24-hour ruler. A glowing orange vertical beam slides across the ruler tracking current time in real-time. Scroll with your mouse wheel anywhere over the timeline to smoothly pan time forward and backward, or swipe horizontally on trackpads. Tap any hour label to jump immediately to that point in the day.

4 3D Point-Cloud Exploded View

The Exploded View renders your entire personal repository inside a slow-rotating 3D celestial sphere. Task and project clusters illuminate with electric tag colors, with particle scale and brightness reflecting project activity. Drag to orbit, wheel to zoom, and click any star node to inspect or re-sort.

Mission Clock & Focus Cockpit

Precision timekeeping meets distraction-free deep work execution with client-side procedural sound generation.

1 Welcome Splash & Dynamic Header Compaction

The top header opens with an expansive editorial title, full acronym breakdown, and rotating tagline carousel. As you scroll down into your tasks, the header smoothly compacts into a sleek, blurred-glass navigation pill with zero layout jitter.

2 Live Mission Clock & Travel Mode

The dashboard features a live 24-hour military Mission Clock with running progress second-bar and formatted date. When traveling across time zones:
• Click the timezone badge or globe icon on the clock to open the Travel Mode selector.
• Choose from popular worldwide hubs (Tokyo, London, Paris, New York, Singapore) or input any IANA timezone (e.g., Europe/Berlin).
• Click Reset to System Local at any time to restore your host's local clock.

3 Context-Aware Header Mini Clock

A compact digital time pill is built directly into the sticky top navigation header. To prevent redundant visual clutter, this mini clock remains strictly hidden while the main Mission Clock is visible in your viewport. It activates automatically only when you scroll past the main clock or navigate to secondary tabs (Timeline, Exploded View, History, Notes, Guide).

4 Focus Cockpit & Sprint Intervals

Click Focus Mode on any task card or launch it from the Command Palette to enter full-screen execution. Choose between 25m Sprint (Pomodoro), 50m Deep Work, 90m Ultradian, or open-ended Stopwatch mode.

5 100% Offline Ambient Sound Deck

The Focus Cockpit features a client-side procedural sound generator built entirely on the HTML5 Web Audio API:
• Brown Noise (1/f²): Deep, warm low-frequency rumble ideal for heavy technical problem solving.
• Pink Noise (1/f): Balanced waterfall frequency curve for reading and writing flow.
• Synthesized Rain: Soft band-filtered white noise texture simulating rainfall against a windowpane.
Zero network requests, zero audio file downloads, and zero cloud tracking—operates seamlessly completely offline.

6 Fleeting Thoughts Scratchpad

Avoid context switching when a distracting idea strikes mid-sprint. Jot thoughts into the in-cockpit scratchpad, then click Save to Task to automatically append them as structured notes on the active task without interrupting your timer.

Shuttle DH610 & Ubuntu 24.04 LTS Deployment

Step-by-step deployment guide for running PETTR in a Docker container on Ubuntu Server with native Tailscale and host Ollama AI integration.

1 Install Tailscale on Ubuntu Host

curl -fsSL https://tailscale.com/install.sh | sh sudo tailscale up

Binds 0.0.0.0:8000. On your phone or laptop on your Tailnet, open http://<shuttle-machine-name>:8000.

2 Configure Host Ollama for Docker Bridge

Install native Ollama and allow internal Docker bridge connections:

curl -fsSL https://ollama.com/install.sh | sh sudo mkdir -p /etc/systemd/system/ollama.service.d echo -e '[Service]\nEnvironment="OLLAMA_HOST=0.0.0.0:11434"\nEnvironment="OLLAMA_ORIGINS=*"' | sudo tee /etc/systemd/system/ollama.service.d/override.conf sudo systemctl daemon-reload && sudo systemctl restart ollama ollama pull llama3.2:3b

3 Deploy with Docker Compose

cd ~/pettr docker compose up -d --build

Docker automatically binds host volumes ./data, ./config, and ./backups, ensuring zero data loss across container updates.

4 Seamless Git Updates

git pull docker compose up -d --build

Shuttle DH610 & Intel 12th Gen Tuning

Configuring the Intel Core i3 12th Gen (4C/8T) and Shuttle DH610 industrial slim chassis for silent, 24/7 low-power operation.

Recommended Hardware, BIOS & Linux Settings

• Hardware Always-On Jumper (JP01): Set the physical JP01 jumper on the Shuttle motherboard to pins 1-2. This forces the system to power on immediately whenever AC power is connected, ensuring 100% headless boot recovery even if the CMOS battery is exhausted.
• BIOS AC Power Loss: In BIOS under Advanced -> Power Management Configuration, verify Restore AC Power Loss is set to Power On.
• Shuttle Smart Fan Profile: Under Advanced -> Smart Fan, set the profile to Ultra-Low Mode or Smart Mode. Shuttle's dual-heatpipe ICE cooling module with twin 60mm fans keeps the i3 under 45°C whisper-quietly.
• Dual Intel LAN (1GbE + 2.5GbE): Plug your primary network cable into the Intel 2.5GbE port for highest local throughput and Tailscale mesh routing.
• Intel P-State Energy Bias: Ubuntu 24.04 (Kernel 6.8+) automatically uses the native intel_pstate driver. Set Energy Performance Preference (EPP) to balance_power for ~7-10W idle draw:

echo "balance_power" | sudo tee /sys/devices/system/cpu/cpu*/cpufreq/energy_performance_preference

Zero Data Loss Architecture

Engineered with industrial SQLite persistence, WAL journaling, and automated compressed snapshots.

SQLite WAL (Write-Ahead Logging) Durability

PETTR initializes SQLite with PRAGMA journal_mode=WAL; and PRAGMA synchronous=NORMAL;. Every write is verified before response. In the event of a sudden power outage or kernel panic, SQLite automatically replays the uncommitted WAL logs upon reboot with zero table corruption.

Persistent Host Bind Mounts

Your database (./data/pettr.sqlite), configuration (./config/pettr_config.json), and backups (./backups/PETTR_*.zip) reside directly on your host NVMe SSD. Rebuilding or pruning Docker containers will never touch or erase your stored data.
